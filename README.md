# Irenimoyan - Professional Portfolio

This is the personal portfolio website of **Tom-Alli Sheu**, a passionate Web Developer dedicated to creating beautiful, efficient, and user-centric web experiences.

## 🚀 Features

- **Modern UI/UX**: A sleek, dark-themed design with glassmorphism and premium aesthetics.
- **Dynamic Animations**: Smooth scroll-triggered animations and micro-interactions for an engaging experience.
- **Responsive Design**: Optimized for all devices, from mobile phones to high-resolution desktops.
- **Standout Hero Section**: A redesigned header featuring a stylized profile presentation and typing effects.
- **Project Showcase**: A curated list of projects with interactive hover states and direct links.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Frameworks**: Bootstrap 5
- **Libraries**: 
  - [AOS](https://michalsnik.github.io/aos/) (Animate On Scroll)
  - [FontAwesome](https://fontawesome.com/) (Icons)
  - [Google Fonts](https://fonts.google.com/) (Outfit, Inter)

## 📁 Structure

```text
├── css/            # Custom and library stylesheets
├── images/         # Project images and assets
├── js/             # Interaction logic and library initializations
├── index.html      # Main entry point
└── README.md       # Project documentation
```

## 💻 Setup & Usage

To run this project locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/irenimoyan/My-Portfolio.git
    ```
2.  Open `index.html` in your favorite browser.
